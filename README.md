# Professional Portfolio Website

**Author:** Isha Pichholiya  
**Organisation:** WeIntern Pvt Ltd  
**Assignment:** Week 1 - Task 1

## Description

A four-page personal portfolio about my frontend development practice. It introduces me, describes the skills I am learning, presents practice projects and includes a contact form demonstration. The original dark navy and mint design is retained, with an optional light theme.

## Technologies used

- HTML5 for page structure and semantic content
- CSS3, custom properties, Flexbox, Grid and media queries
- Vanilla JavaScript for interactive controls
- Google Fonts: DM Sans and Space Grotesk, with browser fallback fonts

## Features

- Home, About, Projects and Contact pages
- Responsive navigation with a mobile menu
- Light/dark theme preference saved in the browser
- Project category filters
- Labelled form fields with required, email and minimum-length validation
- Keyboard focus styles and a skip-to-content link
- Responsive card grids and layouts

The contact form demonstrates validation only. It does not send or store messages. Other Week 1 assignments are submitted separately; their source files are not included in this portfolio.

## Run locally

1. Extract this ZIP into a folder.
2. Open `index.html` in a modern browser such as Chrome, Edge or Firefox.
3. Use the navigation links to visit the other pages.

No installation, build step or configuration is needed. An internet connection loads the optional Google Fonts; the site uses fallback fonts when offline.
